# Mini Rhythm Trainer (4K 節奏打擊訓練器)

一款免安裝、輕量且零外部音檔依賴的 4 鍵（4K）垂直下落式節奏訓練器。  
專注於節奏感知、聽覺同步、手指爆發與穩定度訓練。

🔗 **線上試玩**：[點此立即遊玩]((https://kloc0722.github.io/mini-rhythm-trainer/))

---

## 🌟 專案亮點

- **純前端單檔架構**：整套 App 封裝於單一 `index.html`，以純原生 Web 技術打造，無需任何打包工具或後端環境。
- **純程式合成音訊**：使用 Web Audio API 即時合成節拍器與打擊反饋音，零外連音檔依賴，載入秒開且不需擔心版權或跨域問題。
- **全半拍無縫連續串流**：以 0.5 拍為步進單位，每個半拍必有 Note，無任何空檔，提供極致手感的連續敲擊訓練。
- **高階電競反饋指標**：支援 **Audio Offset 視聽延遲校正**、**osu! 標準 Unstable Rate (UR)** 以及 **Hit Error 極限區間** 統計。

---

## 🎮 操作說明

- **鍵盤配置**：使用 `D`、`F`、`J`、`K` 對應左至右 4 條軌道。
- **開局預備**：點擊「開始」後具備 1 小節（4 拍）倒數準備時間。
- **面板快捷控制**：
  - **重來**：進行中可隨時重置並重新洗出新譜面。
  - **退出**：終止本輪訓練回到待機狀態。
  - **打擊音效切換**：可選擇開啟或靜音按鍵聲，專注對齊節拍器重音。

## 📊 判定機制與結算系統

### 1. 判定窗口 (Timing Windows)
- **PERFECT**：$\vert{}\Delta t\vert{} \le 45\text{ ms}$（+300 分）
- **GOOD**：$45\text{ ms} < \vert{}\Delta t\vert{} \le 90\text{ ms}$（+150 分）
- **BAD**：$90\text{ ms} < \vert{}\Delta t\vert{} \le 140\text{ ms}$（+50 分，斷連擊）
- **MISS**：超出判定線 $> 140\text{ ms}$ 未擊中（斷連擊）

### 2. 結算統計
- **Accuracy (%)**：總打擊精準度百分比。
- **Max Combo**：本輪最高連續命中數。
- **Unstable Rate (UR)**：參照 osu! 標準公式，取已命中偏差的標準差 $\times 10$：
  $$\text{UR} = 10 \times \sqrt{\frac{1}{N}\sum_{i=1}^{N}(\Delta t_i - \bar{\Delta t})^2}$$
- **Hit Error**：記錄整輪敲擊的最早與最晚毫秒極限區間（例如 `-14.2ms ~ +18.5ms`）。
- **Mean Offset**：計算總體敲擊偏早或偏晚的平均傾向值。

## 🛠️ 技術架構

- **繪圖渲染**：HTML5 `<canvas>` + `window.requestAnimationFrame`（60 FPS 幀率渲染）。
- **音效合成**：
  - 節拍器：三角波振盪器（重拍 1200 Hz / 弱拍 800 Hz）搭配短包絡衰減。
  - 按鍵音：正弦波降頻滑音（540 Hz $\to$ 140 Hz）。
- **佈局優化**：畫布尺寸設為 $320 \times 460\text{ px}$，搭配縱向自適應排版（`overflow-y: auto`），在 100% 縮放比例下完整呈現所有控制項。
